# Python Calculator

A simple calculator built with Python and converted into a responsive web application using HTML, CSS, and JavaScript.

🌐 **[Try the Live Calculator](https://moriom-commits.github.io/python-calculator/)**

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Modulus (%)
- Floor Division (//)
- Exponentiation (**)
- Input validation
- Division-by-zero error handling
- Mobile-friendly interface

## Technologies Used

- Python
- HTML
- CSS
- JavaScript
- Git & GitHub
- GitHub Pages

## How to Use

1. Open the live calculator using the link above.
2. Enter two numbers.
3. Select a mathematical operation.
4. Click the Calculate button.
5. View your result!
